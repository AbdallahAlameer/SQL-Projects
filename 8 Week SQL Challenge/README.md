# 8 Week SQL Challenge

This repository contains my solutions and data analysis for the **8 Week SQL Challenge** created by **Danny Ma** ([Data With Danny](https://8weeksqlchallenge.com/)). 

The challenge consists of 8 case studies across various business domains, designed to practice writing production-grade SQL queries to solve real-world analytical problems.

---

## 📌 Case Studies

* **Case Study #1: [Danny's Diner](https://8weeksqlchallenge.com/case-study-1/)** — Customer visit patterns, spending habits, and loyalty program analysis.
* **Case Study #2: [Pizza Runner](https://8weeksqlchallenge.com/case-study-2/)** — Delivery operations, runner performance, and pricing optimization.
* **Case Study #3: [Foodie-Fi](https://8weeksqlchallenge.com/case-study-3/)** — Subscription lifecycle metrics, churn rate, and customer upgrades.
* **Case Study #4: [Data Bank](https://8weeksqlchallenge.com/case-study-4/)** — Financial transactions and cloud data storage allocation.
* **Case Study #5: [Data Mart](https://8weeksqlchallenge.com/case-study-5/)** — Sales performance and sustainable packaging impact analysis.
* **Case Study #6: [Clique Bait](https://8weeksqlchallenge.com/case-study-6/)** — Digital marketing funnel analysis and user web event tracking.
* **Case Study #7: [Balanced Tree Clothing Co.](https://8weeksqlchallenge.com/case-study-7/)** — Retail sales metrics, product performance, and transaction analysis.
* **Case Study #8: [Fresh Segments](https://8weeksqlchallenge.com/case-study-8/)** — Digital marketing metrics and customer interest segmentation.

---

## 🛠️ Key SQL Concepts Covered

* **Aggregations & Grouping:** `GROUP BY`, `HAVING`, summary statistics, and conditional metrics.
* **Data Modeling & Joins:** Multi-table joins (`INNER`, `LEFT`, `FULL`), schema navigation, and relational integrity.
* **Window Functions:** Ranking (`ROW_NUMBER`, `RANK`, `DENSE_RANK`), lead/lag analysis, rolling aggregations, and frame specifications.
* **CTEs & Subqueries:** Modular query structuring using Common Table Expressions and nested logic.
* **Data Transformation:** `CASE WHEN` logic, data type conversions, string manipulation, and date/timestamp parsing.

---

## 📂 Structure

Each case study folder contains:
* The business background and entity-relationship diagram (ERD).
* Complete SQL scripts for schema/table creation and data insertion.
* Formatted SQL queries with solutions to each business question.
