## 🧠 Core Technical Skills Covered

Here are the key SQL concepts and database strategies demonstrated across the projects in this repository:

### 1️⃣ Advanced Data Retrieval & Analytics
* **Complex Aggregations & Grouping:** `GROUP BY`, `HAVING`, multi-level aggregations.
* **Analytical Window Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, running totals, and moving averages.
* **Subqueries & Common Table Expressions (CTEs):** Writing modular, clean, and readable code using `WITH` clauses and nested subqueries.
* **Conditional Logic:** Advanced `CASE WHEN` control flows for data segmentation and custom flag metrics.

### 2️⃣ Data Modeling & Schema Management
* **Data Warehousing Concepts:** Star Schema, Snowflake Schema, Fact & Dimension tables, and Surrogate Keys.
* **Relational Operations:** `INNER JOIN`, `LEFT/RIGHT OUTER JOIN`, `CROSS JOIN`, `SELF JOIN`, and Set Operators (`UNION`, `INTERSECT`).
* **Database Views:** Creating reusable logical views for complex report automation.

### 3️⃣ Optimization & Cloud Platforms
* Query optimization for efficient memory and compute usage.
* Experience querying both traditional relational databases (e.g., PostgreSQL, SQL Server) and Cloud Warehouses (**Snowflake**).
